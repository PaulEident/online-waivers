# BRANDING INSTRUCTIONS FOR CLAUDE CODE

## Logo
Use Volntir SVG logos in navigation:
- **NavBar**: `/public/volntir_app_icon.svg` (28px icon) + "Volntir" text
- **Auth pages**: `/public/volntir_logo_light.svg` (160px wide)
- **Dark backgrounds**: `/public/volntir_logo_dark.svg` (white wordmark)
- **Favicon**: `/public/favicon.svg` (32x32 SVG)

## Colors (Volntir Orange Identity)
- **Primary Brand (orange):** #EA580C → `bg-brand`, `text-brand`
- **Brand Hover:** #C2410C → `hover:bg-brand-hover`
- **Brand Light:** #FFF7ED → `bg-brand-light` (backgrounds, badges)
- **Brand Dark (navy):** #1F2937 → `bg-brand-dark` (headers, dark sections)
- **Success/Accent Green:** #22C55E → `text-accent`, `bg-accent`
- **Gray scale:** Tailwind defaults (gray-50 through gray-900)

## Gradient (for SVG logos)
```
from #C2410C (bottom-left, dark orange)
to #FB923C (top-right, light orange)
```

## Apply To
- Primary buttons → `bg-brand hover:bg-brand-hover`
- Links → `text-brand hover:text-brand-hover`
- Focus rings → `focus:ring-brand`
- Dark header bars → `bg-brand-dark text-white`
- Success states → `text-accent`, `bg-green-100`
- Light accent backgrounds → `bg-brand-light`

## Brand Voice
- "Volntir" (capital V, lowercase rest)
- Tagline: "Volunteering, Together"
- Say "on Volntir" (like "on LinkedIn")
