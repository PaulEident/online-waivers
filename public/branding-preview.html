Usage Guidelines

✅ DO:

  • Use logo.svg for main website header
  • Use logo-icon.svg for app icons, favicons (square format)
  • Use logo-wordmark.svg for minimal contexts
  • Maintain clear space around logo (minimum 20px)
  • Use on white or dark backgrounds

❌ DON'T:

  • Distort, rotate, or skew the logo
  • Change colors (except inverting for dark backgrounds)
  • Add effects (shadows, gradients, etc.)
  • Place on busy backgrounds
  • Make smaller than 24px height

File Paths

All logo files are in public/ directory:

  • /logo.svg - Primary logo (200×60)
  • /logo-icon.svg - Icon only (60×60)
  • /logo-wordmark.svg - Simple wordmark (180×40)
  • /favicon.svg - Favicon (32×32)
